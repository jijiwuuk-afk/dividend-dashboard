# 배당 대시보드 자동뉴스 버전

이 폴더는 그대로 GitHub 저장소에 올리면 됩니다.

자동 동작:
- 매시간 보유종목 관련 Google 뉴스 RSS 확인
- 최근 7일 뉴스에서 종목별 최대 4건 수집
- 중복 제목 제거
- `data/news.json` 자동 갱신
- 홈페이지의 `최신 뉴스` 탭에 최신순 표시

중요:
- 이 뉴스 수집은 기사 제목/출처/링크를 자동 표시하는 기능입니다.
- '추가매수 검토' 판단은 ChatGPT의 별도 자동 점검이 담당합니다.
- 정적 홈페이지만으로 AI 판단까지 자동 반영하려면 별도 AI API 연결이 필요합니다.

GitHub Pages 사용 시:
1. 저장소에 이 폴더 내용 업로드
2. Settings > Pages > Deploy from a branch
3. Branch: main / root 선택
4. 생성된 주소를 휴대폰 Chrome에서 열고 '홈 화면에 추가'
